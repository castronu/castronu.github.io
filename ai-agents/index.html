Four pieces. The pilot has one, the project all of them.

What I build

No.PieceWhat it does
1Operations agents

They investigate an incident by reading the cluster, logs, metrics and code, read-only. When a change is needed they write a plan: a person approves it in an app with no AI in it, and a separate service runs it.

2Pull request reviewer

Comments on every pull request.

3Coding agents

A cloud workstation where Claude Code, Codex and similar tools work on their own and hand back a branch, a pull request and a verified preview environment.

4Shared memory

A Git repository of skills, runbooks and decisions, read by the agents and by the developers' own tools. Every addition goes through review, like code.

Every delivery includes evals: automated tests of how the agents behave, run again on every model or prompt change. The agents work with Slack or Microsoft Teams, GitHub or GitLab, and the models you already use.

Frequently asked questions

Does my data leave my cloud?

The agents run in your account. Data only goes to the model provider you chose.

Can I give the agents write permissions?

Yes. We start from read-only, with every change approved; from there, you decide.

Do I need Kubernetes?

Yes, on AWS, Google Cloud or Azure.

What do I own at the end?

Everything: code, configuration, memory and tests, in your repositories.
