Cosa costruisco

N.PezzoCosa fa
1Agenti per le operazioni

Indagano su un incidente leggendo cluster, log, metriche e codice, in sola lettura. Quando serve una modifica scrivono un piano: lo approva una persona in un'app senza AI e lo esegue un servizio separato.

2Revisore delle pull request

Commenta ogni pull request.

3Agenti che scrivono codice

Una postazione nel cloud dove Claude Code, Codex e strumenti simili lavorano da soli e restituiscono un ramo, una pull request e un ambiente di anteprima verificato.

4Memoria condivisa

Un repository Git di skill, runbook e decisioni, letto dagli agenti e dagli strumenti degli sviluppatori. Ogni aggiunta passa da una revisione, come il codice.

In ogni consegna le eval: test automatici sul comportamento degli agenti, rilanciati a ogni cambio di modello o di prompt. Si collegano Slack o Microsoft Teams, GitHub o GitLab, e i modelli che usi già.
