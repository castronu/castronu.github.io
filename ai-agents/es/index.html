Qué construyo

N.ºPiezaQué hace
1Agentes de operaciones

Investigan un incidente leyendo el clúster, los logs, las métricas y el código, en solo lectura. Cuando hace falta un cambio, escriben un plan: lo aprueba una persona en una aplicación sin IA y lo ejecuta un servicio aparte.

2Revisor de pull requests

Comenta cada pull request.

3Agentes que escriben código

Un puesto de trabajo en la nube donde Claude Code, Codex y herramientas similares trabajan solos y devuelven una rama, una pull request y un entorno de vista previa verificado.

4Memoria compartida

Un repositorio Git de skills, runbooks y decisiones, que leen los agentes y las herramientas de los desarrolladores. Cada añadido pasa por una revisión, como el código.

Cada entrega incluye las evals: pruebas automáticas del comportamiento de los agentes, que se repiten con cada cambio de modelo o de prompt. Los agentes se conectan a Slack o Microsoft Teams, GitHub o GitLab, y a los modelos que ya usas.
