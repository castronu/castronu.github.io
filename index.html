About Me

I design, build and run production AI agent systems. At Sporfie I built the agent platform a small engineering team now works through every day: it investigates production incidents with evidence, runs operations behind human approval, designs and plans features, reviews every pull request, and delegates whole epics to coding agents running in the cloud. It is the same class of product as TierZero (now Cognition) or Resolve.ai, built in-house on AWS Bedrock and MCP, and shipped essentially by one engineer.

Those agents sit on the production platform I built from scratch and have run for ten years at Sporfie, from Kubernetes and GitOps to GPU workloads and CDN. I know how production breaks, which is why my agents are read-only by default, fail-closed on tools, audited on every call, gated by an approval app with no AI in it, and regression-tested with evals before release.

I go full-stack when it speeds delivery. Since 2016 I have also partnered with founders around Geneva as a consultant and fractional CTO. I am open to senior, staff or founding roles where agentic engineering and platform depth compound.

Sporfie Agents (Python / FastAPI, AWS Bedrock, MCP): a multi-agent system for investigation and operations. An LLM router sends each question to one of five specialist agents (infrastructure, operations, design, development, tech lead), each a persona with a fail-closed tool allowlist and its own case memory. 19 read-only MCP servers over Kubernetes, CloudWatch, Prometheus, GitHub, SQL, Jira and more; any change goes through a signed plan, a human approval in an AI-free app and a separate executor, with a full audit trail. Reachable from the web, Slack, Claude Desktop (MCP) and GitHub, where a Tech Lead agent reviews every PR. One LiteLLM gateway gives each agent a key, a budget and a cost per conversation.

CodeDev (TypeScript / Node, React, Kubernetes): a cloud workstation where Claude Code (Agent SDK), Codex and OpenCode build and run the real stack and hand back a branch, a PR and a verified preview URL. Per-branch preview environments, an epic mode that runs parallel agents in git worktrees against a server-checked definition of done, deterministic commit and push guards as hooks, and an MCP so other agents can delegate coding work.

Evals on both halves, so behaviour is checked by code, not by reading transcripts. Sporfie Agents runs a behaviour-regression suite (real model, mocked tools) before every release; CodeDev admits a model only after it passes graded coding and design tasks with a blind review. The target state, which both are built toward: a versioned eval set per agent and per skill, pass rates tracked per model and per prompt change, and a prompt or model swap gated the same way a code change is.
